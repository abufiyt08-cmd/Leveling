GLOW UP OS — PWA INSTALLATION

Isi:
- index.html: aplikasi lengkap
- manifest.json: metadata aplikasi
- sw.js: cache/offline service worker
- icons/: ikon aplikasi

PENTING:
File ZIP ini adalah proyek aplikasi web yang bisa dipasang sebagai PWA setelah di-host di HTTPS. ChatGPT tidak dapat memasangnya langsung ke iPhone Anda atau menerbitkan aplikasi ke App Store.

CARA PALING MUDAH (GitHub Pages):
1. Ekstrak ZIP.
2. Buat repository baru di GitHub.
3. Unggah index.html, manifest.json, sw.js, dan folder icons ke root repository.
4. Buka Settings > Pages.
5. Pilih deploy from branch, pilih main dan /(root), lalu Save.
6. Tunggu URL HTTPS GitHub Pages tersedia.

PASANG DI IPHONE:
1. Buka URL HTTPS GitHub Pages melalui Safari (bukan browser dalam aplikasi).
2. Tekan tombol Share.
3. Pilih Add to Home Screen.
4. Jika tersedia, aktifkan Open as Web App, lalu tekan Add.

PASANG DI ANDROID:
1. Buka URL HTTPS di Chrome.
2. Buka menu tiga titik.
3. Pilih Install app atau Add to Home screen.

FITUR:
- Jadwal kuliah sementara
- Pengelola deadline dan checklist laporan
- Active recall / spaced practice
- Program gym
- Target kalori, protein, tidur, air, dan berat
- Jurnal harian
- Evaluasi 12 minggu
- Penyimpanan lokal browser dan ekspor/impor backup
- Cache offline setelah pertama kali dibuka melalui HTTPS

CATATAN DATA:
Data disimpan pada browser/perangkat yang digunakan. Jangan hapus data situs tanpa mengekspor backup terlebih dahulu. Tidak ada sinkronisasi otomatis antarperangkat atau pengingat push.
Jadwal kuliah dan contoh deadline harus diverifikasi dengan sumber resmi.
